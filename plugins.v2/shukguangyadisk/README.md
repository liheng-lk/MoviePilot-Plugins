# 光鸭云盘助手

MoviePilot 光鸭云盘存储助手。

当前正式版本：**v1.1.1**

## v1.1.1

- 修复 Vue Federation 详情页偶发“数据加载失败”的加载链问题。
- `remoteEntry.js` 改为独立入口并增加前端 cache-bust。
- 增加前端故障隔离，动态模块加载失败时显示具体错误而不是整页报错。
- 临时 DNS/网络异常不再误清空登录态。

## v1.1

- 修复上传目标目录 fileId 失效导致 `code=142 目录不存在`。
- `145/147 任务不存在` 时切换为目标文件可见性确认。
- 增加同名同大小上传幂等检查，避免重复上传。
- 上传后目标文件确认窗口扩展到 90 秒。
