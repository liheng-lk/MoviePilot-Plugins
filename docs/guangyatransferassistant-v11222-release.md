# 光鸭转存助手 v1.12.22 验证记录

## 修复内容

1. 电影匹配到多个频道帖子时，第一个帖子全部候选失败、待复核或被规则拒绝，不再提前终止；继续检查后续匹配帖子。
2. Provider 自动选择跳过尚未被冷却规则重开的 `failed` / `needs_review` 和禁用候选，避免首个失败资源反复占据执行机会。`failed_reopen` / `review_reopen` 仍允许执行。
3. 频道、Provider、观影三个自动执行入口检查真实后台入队回执；入队失败不记为成功 action，不扣除待补集，不发送已选中成功通知。并发槽已被占用时停止生成替代任务。
4. 规划和最终写盘统一使用 completed claim 的有效期规则。旧完成任务在宽限期后仍对应缺集时，不再出现规划阶段放行、最终提交阶段重新阻断的矛盾；新近完成及在途任务继续受保护，当前 worker 排除自身。
