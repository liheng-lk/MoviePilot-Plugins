# 每日助手

## v1.3.1：只做 MoviePilot 订阅

每日助手现在只有一个职责：**监控最新电影和电视剧，并创建 MoviePilot 原生订阅**。

### 工作流程

```text
最新电影 / 最新电视剧
        ↓
多来源增量发现
        ↓
TMDB 精确识别
        ↓
上映/首播日期窗口过滤
        ↓
检查 MoviePilot 媒体库
        ↓
检查 MoviePilot 现有订阅
        ↓
SubscribeChain.add()
```

### 默认行为

- 默认每 10 分钟检查一次，可配置 5～60 分钟。
- 默认监控豆瓣正在上映、即将上映、新片、近期剧集，猫眼电影/剧集、腾讯热播/电视剧以及 TMDB 趋势作为补漏。
- 只接受最近 30 天已经上映/首播，或未来 60 天即将上映/首播的内容；老片老剧即使进入热门榜也不会自动订阅。
- TMDB 无法精确识别的项目不自动订阅。
- 已入库、已订阅项目直接跳过。
- 只调用 MoviePilot `SubscribeChain.add()`。

### 不再包含

v1.3.1 运行入口不再加载或调用 GYSub、光鸭转存、光鸭订阅同步、逐集上映日历或任何转存事件。

旧版本辅助模块仍可能保留在仓库历史中用于版本追溯，但不参与 v1.3.1 运行时。
