# 每日助手

## v1.3.9：最新影视订阅

每日助手现在只有一个职责：**监控最新电影和电视剧，并创建 MoviePilot 原生订阅**。

### 工作流程

```text
最新电影 / 最新电视剧
        ↓
多来源增量发现
        ↓
TMDB 精确识别
        ↓
上映/首播日期窗口过滤
        ↓
检查 MoviePilot 媒体库
        ↓
检查 MoviePilot 现有订阅
        ↓
SubscribeChain.add()
```

### 默认行为

- 默认每 10 分钟检查一次，可配置 5～60 分钟。
- 主源：TMDB 最新电影、TMDB 最新电视剧。\n- 补漏：豆瓣正在上映/即将上映/新片/近期剧集、猫眼电影/剧集、腾讯热播/电视剧。\n- TMDB Trending 不再作为自动订阅来源。
- 只接受最近 30 天已经上映/首播，或未来 60 天即将上映/首播的内容；老片老剧即使进入热门榜也不会自动订阅。
- TMDB 无法精确识别的项目不自动订阅。
- 已入库、已订阅项目直接跳过。
- 只调用 MoviePilot `SubscribeChain.add()`。

### 不再包含

v1.3.1 运行入口不再加载或调用 GYSub、光鸭转存、光鸭订阅同步、逐集上映日历或任何转存事件。

旧版本辅助模块仍可能保留在仓库历史中用于版本追溯，但不参与 v1.3.1 运行时。


### v1.3.5 订阅闭环

- 多季电视剧按 TMDB `season_info.air_date` 展开成独立季候选，不再只处理一季。
- S02/S03/S04 分别拥有独立的媒体库、订阅和历史状态。
- 历史 processed 记录不是永久黑名单：订阅/已存在状态 24 小时复核，媒体库状态 7 天复核。
- 用户手动删除订阅或媒体库内容后，复核会自动释放历史记录，允许重新订阅。
- 电影 TMDB 最新源在请求阶段按最近日期过滤；电视剧不按整剧首播日期截断，避免漏掉老剧新季。


### v1.3.6 国内平台与动漫

默认实时订阅源调整为国内网络优先：

- 腾讯视频直连
- 爱奇艺
- 优酷
- 芒果TV
- 哔哩哔哩剧集
- 哔哩哔哩番剧
- 哔哩哔哩国创
- Bangumi 今日动漫
- 豆瓣动画
- TMDB / 豆瓣 / 猫眼继续用于补漏和统一识别

Netflix、HBO、Disney+、Prime 等海外源仍保留在可选列表中，但不再默认启用，避免网络不可达拖慢每轮检查。

电视剧识别不再要求平台年份必须等于整部剧的首播年份，避免国产剧新季（例如 S02/S03）因为年份不同而无法匹配到 TMDB。


### v1.3.9 来源实测

“保存后立即检查”现在会先从 MoviePilot 宿主网络测试实时来源，再进行订阅扫描。实测内容包括：

- 是否成功返回候选
- 请求耗时
- 候选数量
- 前 8 个标题样本
- 失败原因
- 当前代理开关状态

也可以通过插件 API `/source-test` 单独执行来源实测。

这样腾讯、爱奇艺、优酷、芒果、B站等平台到底哪个接口在当前服务器网络中可用，不再根据外部环境推测，而以 MoviePilot 宿主的真实结果为准。
