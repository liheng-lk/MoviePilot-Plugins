# 光鸭转存助手

MoviePilot V3 专用插件。读取光鸭 Telegram 镜像频道中的光鸭分享链接，并对用户手动勾选的订阅执行“光鸭转存优先、原生下载回退”的精确路由。

## 默认频道
- 光鸭云盘影视热更频道：`https://tgm.li668.asia/regengguangya`
- 光鸭云盘资源分享频道：`https://tgm.li668.asia/yunpanguangya`

## 路由规则
- 未勾选订阅：完全保持 MoviePilot 原生订阅路线。
- 已勾选订阅：先刷新频道索引并匹配光鸭分享；转存成功或同一分享内容已经转存时，本轮不触发下载。
- 无匹配、分享失效或转存失败：默认回退 MoviePilot 原生下载，可在配置中关闭。
- 同一分享链接若文件列表发生变化，指纹会变化，可再次转存以跟进热更。

## 依赖
需要安装并登录同仓库的 `光鸭云盘助手 (ShukGuangYaDisk)`。本插件直接复用其运行态客户端、Token 刷新与目录能力，不保存第二份登录凭据。
